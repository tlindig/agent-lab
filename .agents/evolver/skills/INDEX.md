# Evolver Skills — Index

## Skill Map

Run a skill on user request, or when a procedure or rule references it, in the order that procedure gives.

| Skill                | Purpose                                                                              |
| -------------------- | ------------------------------------------------------------------------------------ |
| `create-agent.md`    | Creates a new agent.                                                                 |
| `rename-agent.md`    | Renames an agent.                                                                    |
| `validate.md`        | Checks a Target Agent's files against fixed rules.                                   |
| `optimize.md`        | Improves a Target Agent's files beyond correctness.                                  |
| `apply-learnings.md` | Applies learnings from `<project_root>/LEARNINGS.md`.                                |
| `sync-agents-md.md`  | Aligns a Target Agent's `<target-project_root>/AGENTS.md` with this repo's baseline. |
